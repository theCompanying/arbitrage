# Amazon PA-API Application Guide

**Status**: Ready to execute  
**Time**: 15-20 minutes  
**Approval wait**: 1-3 business days  

---

## Prerequisites

- Amazon account (create at amazon.com if needed)
- GitHub repo URL: https://github.com/theCompanying/arbitrage (acceptable for application)

---

## Step-by-Step Application

### 1. Join Amazon Associates (5 min)

1. Go to https://affiliate-program.amazon.com/
2. Click "Join now for free"
3. Sign in with Amazon account (or create one)
4. Complete profile:
   - Account type: Individual (or Business if LLC formed)
   - Country: United States
   - Phone verification required

### 2. Add Website/App Information (5 min)

1. In Associates dashboard, go to "Account Settings" → "Website List"
2. Click "Add your website"
3. Enter:
   - **Website URL**: https://github.com/theCompanying/arbitrage
   - **Description**: "Product research tool for arbitrage opportunities between AliExpress and Amazon"
   - **Category**: Shopping/Research
4. Submit for review

### 3. Apply for PA-API Access (5 min)

1. Go to https://webservices.amazon.com/paapi5/documentation/
2. Click "Get Started" or "Apply for API Access"
3. Fill application:
   - **Use case**: "Automated product research and price comparison for arbitrage analysis"
   - **Expected monthly requests**: 10,000-50,000 (free tier sufficient)
   - **Products to promote**: Multiple categories (Electronics, Home, etc.)
4. Submit application

### 4. Wait for Approval (1-3 business days)

- Amazon reviews manually
- Check email for approval notification
- May require additional website verification

### 5. Save Credentials (post-approval)

Once approved, save in secure location:
- Access Key ID
- Secret Access Key
- Associate Tag (e.g., "thecompanying-20")
